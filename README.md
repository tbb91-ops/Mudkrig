# Muldkrig

Et Liero-inspirert ormekrig-spill i sanntid som kjører rett i nettleseren. Grav deg gjennom jorda, sving deg med tauet og skyt motstanderen før han skyter deg. Spill mot datamaskinen eller to spillere på samme tastatur.

## Spill

Åpne `index.html` i en nettleser, eller spill via GitHub Pages.

## Kontroller

**Spiller 1 (mus og tastatur)**

| Handling | Tast |
|---|---|
| Gå | A / D |
| Sikte | Mus |
| Skyt | Venstreklikk (eller F) |
| Tau | Høyreklikk (eller E) |
| Hopp | Mellomrom |
| Grav | S |
| Bytt våpen | Musehjul, Q eller 1–6 |

**Spiller 2 (tastatur)**

| Handling | Tast |
|---|---|
| Gå | ← / → |
| Sikte | ↑ / ↓ |
| Skyt | . |
| Hopp | - |
| Tau | L |
| Bytt våpen | , |
| Grav | ← og → samtidig |

`Esc` eller `P` setter spillet på pause.

## Våpen

Rakett, granat, hagle, maskingevær, klasebombe og laser.

## Regler

- Ny tilfeldig bane hver kamp.
- Faller du i vannet, er du ute.
- Kasser med rødt kors gir 40 liv.
- Først til 5, 10 eller 15 drap vinner.
